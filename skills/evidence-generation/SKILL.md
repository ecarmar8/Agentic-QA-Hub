# Skill: Evidence Generation
## Purpose
Draft traceable QA evidence from supplied requirements, test cases and execution results.
## Procedure
1. Identify scope, build, environment and execution metadata.
2. Count only supplied execution statuses.
3. Link results to test IDs and requirements where data is available.
4. Separate passed, failed, blocked, skipped and unexecuted.
5. List missing evidence and limitations.
6. Produce a concise executive summary and exportable report.
## Guardrails
Never infer execution from a test case definition. Do not fabricate timestamps, screenshots, approvals or tester identities.
